Request:
  {
    "branchId": "uuid",
    "doctorId": "uuid",
    "patientId": "uuid"
  }

Response (200):
  {
    "message": "Agora token generated successfully",
    "data": {
      "token": "string",
      "channelName": "string",
      "uid": number,
      "expiresIn": 86400,
      "expiresAt": timestamp
    }
  }

Error Handling:
  400 - Invalid request
  401 - Unauthorized
